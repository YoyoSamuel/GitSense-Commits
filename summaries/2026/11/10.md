### File-Specific Summary: `Robot/g1_tote/measure_grip.py`

**Timestamp:** 2026-11-10T22:04:27.055Z

**Purpose:**
This script provides a diagnostic utility to analyze the geometry of the G1 robot's grasping posture relative to a tote (box). It aims to verify if the robot's current grasp configuration is physically capable of holding the object by calculating distances and dimensions within the Isaac Sim environment.

**Key Functionalities:**
*   **Environment Initialization:** Sets up the `G1ToteSceneEnvCfg` environment in headless mode and uses a pre-trained `carry` policy (via ONNX) to stabilize the robot in a standing position for two seconds, ensuring measurement reliability compared to previous trial-and-error attempts.
*   **Dimensional Measurement:**
    *   **Tote Size:** Uses `UsdGeom.BBoxCache` to extract the bounding box of the tote prim, converting the 3D dimensions into a clear (x, y, z) output.
    *   **Palm Localization:** Identifies palm links and calculates their coordinates relative to the robot's root (pelvis) frame. It includes logic to transform global world coordinates into the robot's local frame using inverse quaternion application.
    *   **Grasp Validation:** Calculates the lateral distance (gap) between the left and right palms and compares it against the tote's width to determine if the grasp is physically feasible.

**Technical Highlights & Patterns:**
*   **Isaac Lab/Sim Workflow:** Demonstrates standard practices for interacting with Isaac Lab environments, including loading configurations (`apply_carry`), managing policies, and utilizing `omni.usd` for scene introspection.
*   **Data Transformation:** Employs `isaaclab.utils.math` for coordinate transformation, specifically addressing the need to convert world-space vectors into body-local space for robot-centric analysis.
*   **Development Workflow:** Uses `os._exit(0)` to force a shutdown, bypassing the typically slow Isaac Sim cleanup process for automated measurement tasks.
*   **Pending Implementation:** The script contains "TODO" markers for finalizing coordinate frame conversions and refining which specific bounding box dimensions correspond to the grasp width, indicating that this is a work-in-progress diagnostic tool.

The `README.md` details a six-step pipeline:
1.  **`chapter_scraper.py`**: Scrapes chapter text into `chapters_dataset.jsonl`.
2.  **`comment_scraper.py`**: Scrapes reader comments into `comments_dataset.jsonl`.
3.  **`merge_comments.py`**: Distills noisy reader comments into single-voice merged comments using an Ollama-cloud model (`gemma4:31b-cloud`), outputting to `comments_merged.jsonl`. This step requires an `OLLAMA_API_KEY` environment variable.
4.  **`prepare_sft_data.py`**: Builds chat-format Supervised Fine-Tuning (SFT) examples by joining chapters and merged comments, saving to `sft_data/train.jsonl`.
5.  **`train_comment_sft.py`**: Fine-tunes the Qwen base model (default `Qwen/Qwen3.5-9B`) with QLoRA, producing checkpoints and a final adapter in `checkpoints/comment_sft/final/`. It also notes a hardcoded `HF_HOME` environment variable.
6.  **`generate_comments.py`**: Utilizes the fine-tuned model to generate comments for given chapter text.

The `README.md` also provides "Quick start" instructions for inference, including steps for cloning, installing dependencies, logging into Hugging Face, setting the HF cache, downloading the LoRA adapter (initially from `Sam/royalroad-comment-sft`), and running the generation script. It covers `generate_comments.py` flags and explains how to share checkpoints via Hugging Face Hub.

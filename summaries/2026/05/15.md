This `README.md` provides a comprehensive overview of a pipeline designed to scrape RoyalRoad chapters and reader comments, process them into training data, fine-tune a Qwen-based LLM using LoRA, and then use this model to generate realistic reader comments for any given chapter text.

The document details a six-step pipeline:

1.  **`chapter_scraper.py`**: Scrapes top-rated fictions, saving chapter content to `chapters_dataset.jsonl`. It supports resuming and has tunable constants for politeness and limits.
2.  **`comment_scraper.py`**: Crawls best-rated pages to scrape reader comments for each chapter, storing them in `comments_dataset.jsonl`. It automatically resumes from existing data.
3.  **`merge_comments.py`**: Distills noisy real reader comments by grouping them and using an Ollama-cloud model (`gemma4:31b-cloud`) to merge batches into single, casual-toned comments, outputting `comments_merged.jsonl`. This step requires an `OLLAMA_API_KEY`.
4.  **`prepare_sft_data.py`**: Joins chapters with the merged comments to build chat-format SFT (Supervised Fine-Tuning) examples, saving them to `sft_data/train.jsonl`. Chapters are intelligently truncated to focus on the beginning and ending.
5.  **`train_comment_sft.py`**: Fine-tunes a Qwen base model (defaulting to `Qwen3.5-9B`) with QLoRA (4-bit quantization, bf16 LoRA) using TRL's `SFTTrainer`. It logs to Weights & Biases and outputs intermediate checkpoints and a final LoRA adapter. A specific `HF_HOME` environment variable is noted as a hardcoded line that might need adjustment.
6.  **`generate_comments.py`**: The final script for generating comments using either the base model or the fine-tuned LoRA adapter. It takes various inputs like chapter files or inline text, metadata, and generation parameters (e.g., number of comments, temperature).

The `README.md` also includes a "Quick start" guide for inference only, outlining steps for cloning, installing dependencies, logging into Hugging Face (if models are gated), setting HF cache, downloading the LoRA adapter, and running `generate_comments.py`.
